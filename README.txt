TilPro - GitHub Pages upload

Upload all five files directly into the ROOT of your GitHub repository:
1. index.html
2. style.css
3. words.js
4. app.js
5. README.txt

Do not put these files into another folder.

The page loads style.css, words.js and app.js from the same folder as index.html.

To publish: GitHub repository > Settings > Pages > Deploy from a branch > main > /(root) > Save.

Note: This package is the current 4-language vocabulary build. Browser speech quality depends on voices installed in the user's browser/device. Kazakh fallback pronunciation is approximate, not a guaranteed natural Kazakh voice.
